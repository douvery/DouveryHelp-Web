Si una función de Douvery no responde como esperabas, evita repetir acciones sensibles hasta confirmar qué ocurrió.

## Primero revisa el estado del servicio

Consulta [Estados de nuestros servicios](/estados-de-nuestros-servicios). Si existe una incidencia activa, espera a que el servicio se recupere antes de repetir operaciones que puedan generar cambios.

## Si el problema ocurre durante un pago

No pulses repetidamente el botón de pago. Revisa primero si:

- se creó un pedido;
- existe una autorización o cobro en tu banco;
- Douvery muestra un estado de pago activo.

Consulta [Pagos y reembolsos](/soporte/pagos-y-reembolsos) si la operación quedó en un estado incierto.

## Si una página no carga correctamente

Puedes intentar:

1. actualizar la página una vez;
2. comprobar tu conexión;
3. abrir Douvery desde una ventana privada o un navegador actualizado;
4. desactivar temporalmente extensiones que modifiquen páginas o bloqueen solicitudes;
5. volver a iniciar sesión si tu sesión expiró.

Evita borrar datos o repetir procesos críticos si existe una operación pendiente que todavía no has verificado.

## Qué incluir al reportarlo

Cuando contactes soporte, ayuda incluir:

- URL o sección donde ocurrió;
- fecha y hora aproximada;
- pasos realizados antes del error;
- mensaje de error exacto, si aparece;
- navegador y dispositivo;
- captura de pantalla sin información sensible;
- número de pedido, si el problema está relacionado con una compra.

<Warning>
  Oculta contraseñas, códigos de verificación, números completos de tarjeta y cualquier otra credencial antes de enviar una captura.
</Warning>

Si el problema persiste, utiliza los [canales oficiales de contacto](/ayudas-y-mas/contactos).
